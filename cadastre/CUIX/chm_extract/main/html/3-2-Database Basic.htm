Basic Operations of DWG Database

Basic Operations of DWG Database

This chapter introduces basic operations of the DWG database, including creating and retrieving database objects, saving to DWG files, and editing operations on symbol tables and objects within the database.

Creating, Retrieving, and Saving Database Objects

The table below lists common interfaces for creating, retrieving, and saving database objects:

Interface Function
Database.ReadDwgFile Reads the content of a DWG file into a database object (does not open the DWG file as an active document)
Application.DocumentManager.MdiActiveDocument Retrieves the database object of the current active document
Database.SaveAs Saves the database object as a DWG file

Code Examples

1. Read DWG File Content and List All Entity Types

C#

    [CommandMethod("ReadDwgFileTest")]
    public void ReadDwgFileTest()
    {
        Document CurDoc = Application.DocumentManager.MdiActiveDocument;
        Editor curEd = CurDoc.Editor;

        // Create a temporary database (since reading an existing DWG file, do not initialize default objects)
        Database db = new Database(false, true);
        
        // Define the file path to read
        string dwgPath = System.Environment.GetFolderPath(
            Environment.SpecialFolder.MyDocuments) + "\\testDrawing2.dwg";
        
        // Read DWG file into the database (open in shared mode)
        db.ReadDwgFile(dwgPath, FileOpenMode.OpenForReadAndAllShare, false, "");

        // Start transaction
        using (Transaction trans = db.TransactionManager.StartTransaction())
        {
            // Get the model space block table record
            BlockTable blockTable = trans.GetObject(db.BlockTableId, OpenMode.ForRead) as BlockTable;
            BlockTableRecord blockTableRecord = trans.GetObject(
                blockTable[BlockTableRecord.ModelSpace], 
                OpenMode.ForRead) as BlockTableRecord;

            // Iterate through all entities in model space
            Entity entity;
            foreach (ObjectId id in blockTableRecord)
            {
                entity = trans.GetObject(id, OpenMode.ForRead) as Entity;
                curEd.WriteMessage("\nClass name: {0}", entity.GetType());
            }
            trans.Commit(); // Commit transaction (read-only operation, but maintains integrity)
        }
    }

VB

    <CommandMethod("ReadDwgFileTest")>
    Public Sub ReadDwgFileTest()
        Dim CurDoc As Document = Application.DocumentManager.MdiActiveDocument
        Dim curEd As Editor = CurDoc.Editor

        ' Create a temporary database (since reading an existing DWG file, do not initialize default objects)
        Dim db As New Database(False, True)
        
        ' Define the file path to read
        Dim dwgPath As String = System.Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments) & "\testDrawing2.dwg"
        
        ' Read DWG file into the database (open in shared mode)
        db.ReadDwgFile(dwgPath, FileOpenMode.OpenForReadAndAllShare, False, "")

        ' Start transaction
        Using trans As Transaction = db.TransactionManager.StartTransaction()
            ' Get the model space block table record
            Dim blockTable As BlockTable = CType(trans.GetObject(db.BlockTableId, OpenMode.ForRead), BlockTable)
            Dim blockTableRecord As BlockTableRecord = CType(trans.GetObject(blockTable(BlockTableRecord.ModelSpace), OpenMode.ForRead), BlockTableRecord)

            ' Iterate through all entities in model space
            Dim entity As Entity
            For Each id As ObjectId In blockTableRecord
                entity = CType(trans.GetObject(id, OpenMode.ForRead), Entity)
                curEd.WriteMessage(vbCrLf & "Class name: " & entity.GetType().ToString())
            Next
            trans.Commit() ' Commit transaction (read-only operation, but maintains integrity)
        End Using
    End Sub

Execution Result:

Reads the file testDrawing2.dwg in the user's document directory and outputs the types of all entities in the model space.

2. Open a Specified DWG File and Retrieve Its Database Object

C#

    [CommandMethod("OpenDwgFileTest", CommandFlags.Session)] //Note: Requires Session mode registration due to document opening
    public void OpenDwgFileTest()
    {
        string dwgPath = System.Environment.GetFolderPath(
            Environment.SpecialFolder.MyDocuments) + "\\testDrawing2.dwg";
        
        // Get the document manager
        DocumentCollection docMgr = Application.DocumentManager;
        
        // Open the specified drawing file
        Document doc = docMgr.Open(dwgPath, false);
        
        // Set as the current active document
        docMgr.MdiActiveDocument = doc;

        // Retrieve the database object of document doc
        Database db = doc.Database;
    }

3. Create a Database Object and Save as a DWG File

C#

    [CommandMethod("CreateDwgTest")]
    public void CreateDwgTest()
    {
        // Get the current active document and editor
        Document CurDoc = Application.DocumentManager.MdiActiveDocument;
        Editor curEd = CurDoc.Editor;

        // Create a new database (initialize default objects)
        Database db = new Database();
        
        // Perform database operations using a transaction
        using (Transaction trans = db.TransactionManager.StartTransaction())
        {
            // Get the Block Table
            BlockTable blockTable = trans.GetObject(db.BlockTableId, OpenMode.ForRead) as BlockTable;
            
            // Get the Model Space BlockTableRecord
            BlockTableRecord blockTableRecord = trans.GetObject(
                blockTable[BlockTableRecord.ModelSpace], 
                OpenMode.ForWrite) as BlockTableRecord;

            // Create a Circle object (center at origin, radius 500)
            Circle circle = new Circle(new Point3d(0, 0, 0), Vector3d.ZAxis, 500.0);
            
            // Add the circle to Model Space
            blockTableRecord.AppendEntity(circle);
            
            // Register the new object with the transaction
            trans.AddNewlyCreatedDBObject(circle, true);
            
            // Commit the transaction (confirm changes)
            trans.Commit();
        }

        string dwgPath = System.Environment.GetFolderPath(
            Environment.SpecialFolder.MyDocuments) + "\\testDrawing2.dwg";
        
        try
        {
            // Save the database as a DWG file (using the current version format)
            db.SaveAs(dwgPath, DwgVersion.Current);
        }
        catch (System.Exception e)
        {
            curEd.WriteMessage("\nFailed to save! Exception: {0}", e.Message);
            return;
        }
        curEd.WriteMessage("\nSave successfully!");
    }

Editing Symbol Tables and Objects in the Database

The ObjectIds of symbol tables are stored in the properties of the database object. For example, to get the Block Table's ObjectId, read the Database.BlockTableId property; to get the Layer Table's ObjectId, read the Database.LayerTableId property, and so on.

To edit objects in the database, you typically need to obtain their ObjectIds. There are two common ways to get ObjectIds: one is through user interaction interfaces (covered in later chapters), and the other is by traversing BlockTableRecords (such as Model Space, Paper Space, or ordinary block definitions) to retrieve the ObjectIds of contained objects.

Code Examples

1. Add a Line to Model Space

C#

    [CommandMethod("DrawLine", CommandFlags.Modal)]
    public void DrawLine()
    {
        // Get the current document and database
        Document objDoc = Application.DocumentManager.MdiActiveDocument;
        Database objDB = objDoc.Database;
        
        // Start a transaction
        Transaction trans = objDoc.TransactionManager.StartTransaction();
        
        // Get the Model Space BlockTableRecord, opened for write
        BlockTable zcBLT = (BlockTable)trans.GetObject(objDB.BlockTableId, OpenMode.ForRead);
        BlockTableRecord zcBLTR = (BlockTableRecord)trans.GetObject(zcBLT[BlockTableRecord.ModelSpace], OpenMode.ForWrite);
    
        using (trans)
        {
            // Create start and end points
            Point3d ptStart = new Point3d(0, 0, 0);
            Point3d ptEnd = new Point3d(100, 100, 0);
            
            // Create a Line object and set its coordinates
            Line objLine = new Line();
            objLine.StartPoint = ptStart;
            objLine.EndPoint = ptEnd;
            
            // Add the line to the model space
            zcBLTR.AppendEntity(objLine);
            trans.AddNewlyCreatedDBObject(objLine, true); 
            
            trans.Commit(); // Commit the transaction (save changes)
        }
    }

        End Using
End Sub

2. Modify coordinates of all lines in model space

C#

    [CommandMethod("ModLine", CommandFlags.Modal)]
    public void ModLine()
    {
        Document objDoc = Application.DocumentManager.MdiActiveDocument;
        Database objDB = objDoc.Database;
        
        using (Transaction trans = objDoc.TransactionManager.StartTransaction())
        {
            // Get the model space block table record in write mode
            BlockTable zcBLT = (BlockTable)trans.GetObject(objDB.BlockTableId, OpenMode.ForRead);
            BlockTableRecord zcBlkTblRec = trans.GetObject(zcBLT[BlockTableRecord.ModelSpace], OpenMode.ForWrite) as BlockTableRecord;
    
            // Iterate all entities in model space, open entities in write mode
            foreach (ObjectId entOid in zcBlkTblRec)
            {
                Entity ent = trans.GetObject(entOid, OpenMode.ForWrite) as Entity;
                
                // Process only Line objects
                if (ent != null && ent.GetType() == typeof(Line))
                {
                    Line line = ent as Line;
                    // Modify line start and end points
                    Point3d startPoint = new Point3d(0, 100, 0);
                    Point3d endPoint = new Point3d(100, 0, 0);
                    line.StartPoint = startPoint;
                    line.EndPoint = endPoint;
                }
            }
            trans.Commit(); // Commit changes
        }
    }

VB

    <CommandMethod("ModLine", CommandFlags.Modal)>

                    Dim startPoint As New Point3d(0, 100, 0)
                    Dim endPoint As New Point3d(100, 0, 0)
                    line.StartPoint = startPoint
                    line.EndPoint = endPoint
                End If
            Next
            
            ' Commit changes
            trans.Commit()
        End Using
    End Sub

3. Delete user-selected lines

C#

    [CommandMethod("EraseLine", CommandFlags.Modal)]
    public void EraseLine()
    {
        Document objDoc = Application.DocumentManager.MdiActiveDocument;
        
        // Prompt user to select a line to delete
        PromptEntityResult result = objDoc.Editor.GetEntity("\nSelect a line");
        if (result.Status != PromptStatus.OK)
            return;
    
        // Start transaction
        Transaction trans = objDoc.TransactionManager.StartTransaction();
        using (trans)
        {
            // Get the selected entity in write mode
            Entity entity = (Entity)trans.GetObject(result.ObjectId, OpenMode.ForWrite);
            
            // Confirm it is a line and delete
            if (entity != null && entity.GetType() == typeof(Line))
            {
                Line line = entity as Line;
                line.Erase(); // Perform deletion
            }
            trans.Commit(); // Commit deletion
        }
    }

4. Create and Modify Layers

C#

    [CommandMethod("LayerSample")]
    public void LayerSample()
    {
        // Get the current working database and its document object
        Database db = HostApplicationServices.WorkingDatabase;
        Document doc = Application.DocumentManager.GetDocument(db);
    
        // Start a database transaction
        using (Transaction trans = db.TransactionManager.StartTransaction())
        {
            // Get the layer table
            LayerTable lyrTbl = (LayerTable)trans.GetObject(db.LayerTableId, OpenMode.ForRead);
    
            // Check if "Layer 1" exists
            if (lyrTbl.Has("Layer 1"))
            {
                // Iterate through all layers in the layer table
                foreach (ObjectId id in lyrTbl)
                {
                    // Skip erased layers
                    if (!id.IsErased)
                    {
                        LayerTableRecord lyrTblRec = (LayerTableRecord)trans.GetObject(id, OpenMode.ForWrite);
                        
                        // Modify the target layer
                        if (lyrTblRec.Name == "Layer 1")
                        {
                            lyrTblRec.Name = "Layer 2";             // Rename the layer
                            lyrTblRec.IsOff = false;                // Turn on the layer
                            lyrTblRec.IsFrozen = false;             // Unfreeze the layer
                            lyrTblRec.IsLocked = false;             // Unlock the layer
    
                            // Set layer color to green
                            Color color = new Color();
                            color.SetRgb(0, 255, 0);
                            lyrTblRec.Color = color;
    
                            lyrTblRec.ViewportVisibilityDefault = false;  // Hide in viewport by default
                            
                            // Set transparency (127 means ~50% opacity)
                            Byte trParByte = 127;
                            Transparency transparency = new Transparency(trParByte);
                            lyrTblRec.Transparency = transparency;
                        }
                    }
                }
            }
            else
            {
                // Create a new layer record
                LayerTableRecord lyrTblRec = new LayerTableRecord();
                lyrTblRec.Name = "Layer 1";                 // Set layer name
                lyrTblRec.IsOff = true;                     // Turn off the layer
                lyrTblRec.IsFrozen = true;                  // Freeze the layer
                lyrTblRec.IsLocked = true;                  // Lock the layer
    
                // Set layer color to red
                Color color = new Color();
                color.SetRgb(255, 0, 0);
                lyrTblRec.Color = color;
    
                lyrTblRec.ViewportVisibilityDefault = true; // Show in viewport by default
                
                // Set transparency to ByLayer
                Transparency transparency = new Transparency(TransparencyMethod.ByLayer);
                lyrTblRec.Transparency = transparency;
    
                // Add the new layer to the layer table
                lyrTbl.UpgradeOpen();                      // Switch layer table to write mode
                lyrTbl.Add(lyrTblRec);                     // Add the new layer to the table
                trans.AddNewlyCreatedDBObject(lyrTblRec, true);  // Register the new object
            }
            
            trans.Commit();  // Commit the transaction (save changes)
        }
    }

VB

    <CommandMethod("LayerSample", CommandFlags.Modal)>
    Public Sub LayerSample()
        ' Get the current working database and its document object
        Dim db As Database = HostApplicationServices.WorkingDatabase
        Dim doc As Document = Application.DocumentManager.GetDocument(db)

        ' Start a database transaction
        Using trans As Transaction = db.TransactionManager.StartTransaction()
            ' Get the layer table
            Dim lyrTbl As LayerTable = CType(trans.GetObject(db.LayerTableId, OpenMode.ForRead), LayerTable)

            ' Check if "Layer 1" exists
            If lyrTbl.Has("Layer 1") Then
                ' Iterate through all layers in the layer table
                For Each id As ObjectId In lyrTbl
                    ' Skip erased layers
                    If Not id.IsErased Then
                        Dim lyrTblRec As LayerTableRecord = CType(trans.GetObject(id, OpenMode.ForWrite), LayerTableRecord)

                        ' Modify the target layer
                        If lyrTblRec.Name = "Layer 1" Then
                            lyrTblRec.Name = "Layer 2" ' Rename the layer
                            lyrTblRec.IsOff = False    ' Turn on the layer
                            lyrTblRec.IsFrozen = False ' Unfreeze the layer
                            lyrTblRec.IsLocked = False ' Unlock the layer

                            ' Set layer color to green
                            Dim color As New Color()
                            color.SetRgb(0, 255, 0)
                            lyrTblRec.Color = color

                            lyrTblRec.ViewportVisibilityDefault = False ' Hide in viewport by default

                            ' Set transparency (127 means ~50% opacity)
                            Dim trParByte As Byte = 127
                            Dim transparency As New Transparency(trParByte)
                            lyrTblRec.Transparency = transparency
                        End If
                    End If
                Next
            Else
                ' Create a new layer record
                Dim lyrTblRec As New LayerTableRecord()
                lyrTblRec.Name = "Layer 1" ' Set layer name
                lyrTblRec.IsOff = True     ' Turn off the layer
                lyrTblRec.IsFrozen = True ' Freeze the layer
                lyrTblRec.IsLocked = True ' Lock the layer

                ' Set layer color to red
                Dim color As New Color()
                color.SetRgb(255, 0, 0)
                lyrTblRec.Color = color

                lyrTblRec.ViewportVisibilityDefault = True ' Default display in viewport

                ' Set transparency to ByLayer
                Dim transparency As New Transparency(TransparencyMethod.ByLayer)
                lyrTblRec.Transparency = transparency

                ' Add the new layer to the layer table
                lyrTbl.UpgradeOpen() ' Elevate layer table to write mode
                lyrTbl.Add(lyrTblRec) ' Add new layer to layer table
                trans.AddNewlyCreatedDBObject(lyrTblRec, True) ' Register new object to the database
            End If

            trans.Commit() ' Commit transaction (save all changes)
        End Using
    End Sub

Execution Result:

If a layer named Layer 1 does not exist, create it; if it already exists, rename it to Layer 2 and modify its properties
