DWG Database Overview

DWG Database Structure Overview

The DWG database is the core storage structure of ZWCAD graphic files, organizing data hierarchically. All graphical objects (e.g., lines, circles, block references), non-graphical objects (e.g., layers, linetypes), and dictionaries are stored in this database. Key components include:

Symbol Tables: Store specific types of objects as table records. Examples include the Block Table for blocks, Layer Table for layers, and Linetype Table for linetypes.

Named Object Dictionary: The root container for user-defined data and certain DWG data, also known as the root dictionary, which can nest sub-dictionaries.

Note: The DWG database is single-threaded and supports only single-threaded operations.

Concept and Classification of Symbol Tables

Definition of Symbol Tables

Symbol tables are containers in ZWCAD for managing specific types of objects. Each symbol table stores a group of table records (TableRecord) of the same type. Symbol tables are built-in structures of the database; developers cannot directly create or delete them.

Common Symbol Tables and Functions

Symbol Table Type Stored Content Typical Operations
BlockTable Block definitions (BlockTableRecord) Retrieve model space and paper space block table records; create or traverse block definitions
LayerTable Layer properties (color, linetype, etc.) Control layer visibility, freeze, and lock states
LinetypeTable Linetype definitions (e.g., dashed, dotted) Add linetypes
TextStyleTable Text styles (font, height, etc.) Add or modify custom text styles
DimStyleTable Dimension styles (arrows, tolerances, etc.) Add or modify custom dimension styles
UcsTable Coordinate systems Add or modify custom coordinate systems
ViewportTable Viewports Add or modify viewports
RegAppTable Application names Add or modify secondary development application names

Role and Usage of Transactions

Necessity of Transactions

Ensure atomicity of database operations (commit or rollback).

Manage object locking states to prevent modification conflicts.

Basic Workflow

C#

    // Start transaction
    using (Transaction tr = db.TransactionManager.StartTransaction()) {
        try {
            // Operate on database objects
            // ...

            // If all operations succeed, commit the transaction
            tr.Commit();
        } catch {
            // If an exception occurs, roll back the transaction
            tr.Abort();
        }
    }

VB

        ' ...

        tr.Commit()
    Catch ex As Exception
        ' If an exception occurs, roll back the transaction
        tr.Abort()
    End Using

Detailed Explanation of BlockTable

Structure of BlockTable

The BlockTable is one of the most important symbol tables in the DWG database, containing all block definitions (BlockTableRecord). Each block definition can include multiple graphical entities (Entity), such as lines, circles, or nested block references.

Common Operation Examples

1. Creating Entities in Model Space

C#

    // Start transaction
    using (Transaction tr = db.TransactionManager.StartTransaction()) {
        // Get BlockTable
        BlockTable bt = tr.GetObject(db.BlockTableId, OpenMode.ForRead) as BlockTable;
    
        // Get Model Space BlockTableRecord
        BlockTableRecord modelSpace = tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForWrite) as BlockTableRecord;
        
        // Add a line to Model Space
        Line line = new Line(new Point3d(0, 0, 0), new Point3d(100, 100, 0));
        modelSpace.AppendEntity(line);
        tr.AddNewlyCreatedDBObject(line, true);
    
        // Commit transaction
        tr.Commit(); 
    }

VB

    ' Start transaction
    Using tr As Transaction = db.TransactionManager.StartTransaction()
        ' Get BlockTable
        Dim bt As BlockTable = TryCast(tr.GetObject(db.BlockTableId, OpenMode.ForRead), BlockTable)

        ' Get Model Space BlockTableRecord
        Dim modelSpace As BlockTableRecord = TryCast(tr.GetObject(bt(BlockTableRecord.ModelSpace), OpenMode.ForWrite), BlockTableRecord)
        
        ' Add a line to Model Space
        Dim line As New Line(New Point3d(0, 0, 0), New Point3d(100, 100, 0))
        modelSpace.AppendEntity(line)
        tr.AddNewlyCreatedDBObject(line, True)
        
        ' Commit transaction
        tr.Commit()
    End Using

2. Create a Block Definition and Insert a Block Reference in Model Space

C#

    // Start transaction
    using (Transaction tr = db.TransactionManager.StartTransaction()) {
        // Get BlockTable
        BlockTable bt = tr.GetObject(db.BlockTableId, OpenMode.ForRead) as BlockTable;
    
        // Get Model Space BlockTableRecord
        BlockTableRecord modelSpace = tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForWrite) as BlockTableRecord;
    
        // Create a new BlockTableRecord
        BlockTableRecord newBlock = new BlockTableRecord();
        newBlock.Name = "MyBlock";
        bt.UpgradeOpen();
        bt.Add(newBlock);
        tr.AddNewlyCreatedDBObject(newBlock, true);
    
        // Add a line to the block
        Line line = new Line(new Point3d(0, 0, 0), new Point3d(100, 100, 0));
        newBlock.AppendEntity(line);
        tr.AddNewlyCreatedDBObject(line, true);

        // Insert a BlockReference in Model Space
        BlockReference br = new BlockReference(new Point3d(0, 0, 0), newBlock.ObjectId);
        modelSpace.AppendEntity(br);
        tr.AddNewlyCreatedDBObject(br, true);

        // Commit transaction
        tr.Commit();
    }

Conversion Between Objects, ObjectId, and Handles

Core Concepts

Object (DBObject): An actual data instance in the database (e.g., Line, BlockReference).

ObjectId: A unique identifier for an object, valid only within the current session (e.g., from document open to close).

Handle: A globally unique identifier for an object, persisted across sessions (i.e., remains unchanged after reopening the document).

Conversion Methods

C#

    // Get ObjectId from Handle, where handle is a known Handle object
    ObjectId id = db.GetObjectId(false, handle, 0);
    
    // Get Object from ObjectId, where id is a known ObjectId and tr is an active transaction
    Line line = tr.GetObject(id, OpenMode.ForRead) as Line;

    // Get Handle from Object, where obj is a known DBObject
    Handle handle = obj.Handle;

VB

    ' Get ObjectId from Handle, where handle is a known Handle object
    Dim id As ObjectId = db.GetObjectId(False, handle, 0)
    
    ' Get Object from ObjectId, where id is a known ObjectId and tr is an active transaction
    Dim line As Line = TryCast(tr.GetObject(id, OpenMode.ForRead), Line)
    
    ' Get Handle from Object, where obj is a known DBObject
    Dim handle As Handle = obj.Handle

Named Object Dictionary

The Named Object Dictionary is the root container for user-defined data, manipulated via the DBDictionary class. Key features include:

Can store other sub-dictionaries or extension records (XRecord).

Commonly used to store global configurations or user-specific data.

Operation Example

C#

    using (Transaction tr = db.TransactionManager.StartTransaction()) {
        // Get Named Object Dictionary
        DBDictionary nod = tr.GetObject(db.NamedObjectsDictionaryId, OpenMode.ForWrite) as DBDictionary;

        // Create a sub-dictionary
        DBDictionary myDict = new DBDictionary();
        nod.SetAt("MyAppData", myDict);
        tr.AddNewlyCreatedDBObject(myDict, true);

        // Store XRecord
        XRecord xrec = new XRecord();
        myDict.SetAt("Config", xrec);
        // Set XRecord data using ResultBuffer and TypedValue
        xrec.Data = new ResultBuffer(new TypedValue(1001, "MyApp"), new TypedValue(40, 3.14));

        tr.Commit();
    }

VB

    Using tr As Transaction = db.TransactionManager.StartTransaction()
        ' Get the named dictionary object
        Dim nod As DBDictionary = TryCast(tr.GetObject(db.NamedObjectsDictionaryId, OpenMode.ForWrite), DBDictionary)

        ' Create a sub-dictionary
        Dim myDict As New DBDictionary()
        nod.SetAt("MyAppData", myDict)
        tr.AddNewlyCreatedDBObject(myDict, True)

        ' Store XRecord
        Dim xrec As New XRecord()
        myDict.SetAt("Config", xrec)
        ' Set XRecord data using ResultBuffer and TypedValue
        xrec.Data = New ResultBuffer(New TypedValue(1001, "MyApp"), New TypedValue(40, 3.14))

        ' Commit the transaction
        tr.Commit()
    End Using

Extended Data (XData) and Extension Dictionary (XRecord)

Extended Data (XData)

Custom data attached to an object, accessed through the object's XData property:

C#

    using (Transaction tr = doc.TransactionManager.StartTransaction())
    {
        // Retrieve the specified entity object from the database in write mode
        // id is the ObjectId of a previously acquired entity
        Entity entity = (Entity)tr.GetObject(id, OpenMode.ForWrite);
    
        // Get the RegAppTable (Registration Application Table) in write mode
        // This table stores application-related extended data
        RegAppTable regTable = (RegAppTable)tr.GetObject(db.RegAppTableId, OpenMode.ForWrite);
    
        // Define the registered application name to find or create
        String strAppName = "MyApp";
    
        // Check if the registered application name already exists in the table
        if (!regTable.Has(strAppName))
        {
            // If not, create a new RegAppTableRecord
            RegAppTableRecord regAppTableRecord = new RegAppTableRecord();
            // Set the registered application name
            regAppTableRecord.Name = strAppName;
            regTable.Add(regAppTableRecord);
            tr.AddNewlyCreatedDBObject(regAppTableRecord, true);
        }
    
        // Set extended data (XData) for the entity object
        // XData can contain custom application data
        entity.XData = new ResultBuffer(
            // The first TypedValue represents the registered application name
            new TypedValue((int)DxfCode.ExtendedDataRegAppName, strAppName),
            // The second TypedValue represents an ASCII string ("hello")
            new TypedValue((int)DxfCode.ExtendedDataAsciiString, "hello"),
            // The third TypedValue represents a 32-bit integer (2)
            new TypedValue((int)DxfCode.ExtendedDataInteger32, 2),
            // The fourth TypedValue represents a real number (3.14)
            new TypedValue((int)DxfCode.ExtendedDataReal, 3.14)
        );
    
        tr.Commit();
    }

        tr.Commit()
    End Using

Extension Dictionary (ExtensionDictionary)

Different from named dictionaries, the extension dictionary is attached to the object and can be accessed via the object's ExtensionDictionary property. Other operations are consistent with regular dictionary objects:

C#

    using (Transaction tr = doc.TransactionManager.StartTransaction())
    {
        // Retrieve the specified entity object from the database in write mode
        // id is the ObjectId of a previously acquired object
        Entity entity = (Entity)tr.GetObject(id, OpenMode.ForWrite);
    
        // Check if the object has an extension dictionary; create one if not
        if (entity.ExtensionDictionary == ObjectId.Null)
        {
            entity.CreateExtensionDictionary();
        }
    
        ObjectId objId = entity.ExtensionDictionary;   
        // Open the extension dictionary in write mode
        DBDictionary dict = (DBDictionary)tr.GetObject(objId, OpenMode.ForWrite);
    
        // Check if the extension dictionary contains an entry named "MyRec"
        if (!dict.Contains("MyRec"))
        {
            // If not, create a new Xrecord object
            Xrecord xr = new Xrecord();
    
            // Create a ResultBuffer to store data for the Xrecord

    Using tr As Transaction = doc.TransactionManager.StartTransaction()
    ' Retrieve the specified entity object from the database, opened in write mode
    ' id is the ObjectId of a previously obtained object
    Dim entity As Entity = CType(tr.GetObject(id, OpenMode.ForWrite), Entity)

    ' Check if the object has an extension dictionary; create one if not
    If entity.ExtensionDictionary = ObjectId.Null Then
        entity.CreateExtensionDictionary()
    End If

    Dim objId As ObjectId = entity.ExtensionDictionary
    ' Open the extension dictionary in write mode
    Dim dict As DBDictionary = CType(tr.GetObject(objId, OpenMode.ForWrite), DBDictionary)

    ' Check if the extension dictionary already contains an entry named "MyRec"
    If Not dict.Contains("MyRec") Then
        ' If not, create a new Xrecord object
        Dim xr As New Xrecord()

        ' Create a ResultBuffer to store data for the Xrecord
        ' Contains a string "hello", a 32-bit integer 2, and a real number 3.14
        Dim rb As New ResultBuffer(New TypedValue() {(CInt(DxfCode.Text), "hello"), (CInt(DxfCode.Int32), 2), (CInt(DxfCode.Real), 3.14)})

        ' Set the ResultBuffer as the Xrecord's data
        xr.Data = rb

        ' Add the Xrecord to the extension dictionary with the key "MyRec"
        dict.SetAt("MyRec", xr)

        ' Add the newly created Xrecord object to the transaction for database persistence
        tr.AddNewlyCreatedDBObject(xr, True)
    End If

    tr.Commit()
End Using
