Introduction to ZWCAD COM Components

Description

In ZWCAD, COM technology is widely used in various plugins and applications to extend and customize ZWCAD's functionality. The COM interfaces provided by ZWCAD are key to utilizing COM technology. They offer a set of interfaces and methods for accessing ZWCAD's object model and controlling its various features and tools.

Basic Concepts of COM Interfaces:

COM (Component Object Model) is an object-oriented component technology designed to abstract software system components into standardized interfaces and methods, enabling interaction and communication between different software systems and programming languages. COM interfaces are the core of COM technology, defining standardized interaction methods between components to allow seamless invocation and collaboration. In ZWCAD, COM interfaces play an equally important role. Through a set of standardized interfaces and methods, they provide access to ZWCAD's object model and support control over its features and tools. ZWCAD offers extensive COM interfaces covering elements and functionalities such as the application, drawing documents, layers, blocks, entities, text, dimensions, and more, enabling developers to flexibly manipulate and extend ZWCAD's capabilities. Each COM interface has a unique identifier called a GUID (Globally Unique Identifier). A GUID is a 128-bit number used to uniquely identify a COM interface or component. In ZWCAD, each COM interface is assigned a GUID to ensure its uniqueness and recognizability within the system. Through GUIDs, developers can accurately reference and invoke specific COM interfaces, achieving efficient interaction with ZWCAD. In summary, COM technology provides ZWCAD with powerful extensibility and cross-language support through standardized interfaces and methods, while GUIDs ensure the uniqueness and accessibility of interfaces, offering developers a stable and flexible programming environment.

Classification of COM Interfaces:

In ZWCAD, COM interfaces can be classified based on their functionality and purpose. Below are common COM interface categories in ZWCAD:

1. ZcadApplication Interface: Controls the ZWCAD application, e.g., starting, closing, saving, printing, exiting.

2. ZcadDocument Interface: Accesses ZWCAD drawing documents, e.g., creating, opening, saving, closing, refreshing.

3. ZcadDatabase Interface: Accesses ZWCAD databases, e.g., layers, blocks, entities.

4. ZcadBlock Interface: Manages ZWCAD blocks, e.g., creating, inserting, deleting, copying.

5. ZcadEntity Interface: Manages ZWCAD entity objects, e.g., creating, inserting, deleting, editing.

6. ZcadText Interface: Manages ZWCAD text objects, e.g., creating, inserting, editing, formatting.

7. ZcadDimension Interface: Manages ZWCAD dimension objects, e.g., creating, inserting, editing, formatting.

8. ZcadLayer Interface: Manages ZWCAD layer objects, e.g., creating, configuring, displaying, hiding.

9. ZcadSelectionSet Interface: Manages ZWCAD selection sets, e.g., creating, adding, deleting, editing.

10. ZcadPlot Interface: Manages ZWCAD printing and output settings, e.g., print area, output devices, file formats.

These are common COM interface categories in ZWCAD. Each interface provides standardized methods and properties to access and control corresponding functionalities and objects.

Methods for Using COM Interfaces:

1. Creating a ZWCAD Application Object:

To access ZWCAD's object model via COM technology, first create a ZWCAD application object, i.e., a ZcadApplication object. Use the CreateObject function to instantiate the ZcadApplication object, e.g.:

using ZwSoft.ZwCAD.Interop;
ZcadApplication zcadApp = Activator.CreateInstance(Type.GetTypeFromProgID("ZWCAD.Application.2026")) as ZcadApplication;

To show or hide the ZWCAD interface, set the Visible property:

zcadApp.Visible = true; // Control ZWCAD UI visibility

Additionally, ZcadApplication includes practical functions such as LoadZrx/UnloadZrx for loading/unloading ZRX programs, and ZoomAll/ZoomExtents/ZoomCentered for viewport scaling.

Use properties like ActiveDocument to retrieve the active document, Documents to access all open documents, MenuGroups to manage menu groups, and MenuBar to access the current menu.

2. Opening or Creating a Drawing Document Object:

Open or create a ZWCAD drawing document object (ZcadDocument) via the Documents property of the ZcadApplication object, e.g.:

using ZwSoft.ZwCAD.Interop;
Object ReadOnly = false;
Object Password = Type.Missing;
ZcadDocument Doc = zcadApp.Documents.Open(DwgFilePath, ReadOnly, Password);

ZcadDocument also provides functions like SendCommand/PostCommand to send commands to ZWCAD, and New/Open/Save/Close to manage documents.

Properties such as ModelSpace/PaperSpace access model/paper space objects, and Utility provides helper functions via the ZcadUtility class.

3. Accessing and Controlling ZWCAD Objects:

Use methods and properties of the ZcadDocument object to access and control ZWCAD objects. For example, use the Layers property to manage layers, or add entities to model space via ModelSpace:

using ZwSoft.ZwCAD.Interop;

 ZcadLayer layer = Doc.Layers.Add("Layer1");
 ZcadModelSpace ms = Doc.ModelSpace;
 ms.AddCircle(new double[] { 0, 0, 0 },10);
 ms.AddText("Hello World", new double[] { 0, 0, 0 }, 2.5);

4. Close the document and exit the ZWCAD application:

After completing the operation, it is necessary to close and exit the ZWCAD application. You can use the Quit method of the ZcadApplication object to exit the ZWCAD application, for example:

using ZwSoft.ZwCAD.Interop;
Doc.Save();
Doc.Close();
zcadApp.Quit();
