Reactors and Events

Events are notifications or messages issued by ZWCAD to inform you about the status of the current session or alert you to specific actions. For example, the ObjectModified event is triggered when an entity is modified. Additionally, other events are fired when a drawing is closed, a command starts, or a system variable changes. Based on these event signals, you can write subroutines or event handlers to track drawing modifications, record time spent by users on specific drawings, or execute additional operations in response to these actions. Overall, events are an advanced feature that, when utilized effectively, can enable the development of powerful and practical functionalities, significantly enhancing user experience and operational efficiency.
