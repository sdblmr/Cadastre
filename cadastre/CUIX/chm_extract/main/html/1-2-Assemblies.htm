Introduction to ZWCAD .NET Assemblies

Common Assemblies Introduction

ZWCAD .NET API assemblies are composed of various DLL files containing classes, structures, methods, and events that provide access to objects in drawing files or the application. Each DLL defines distinct namespaces to organize library components by functionality.

Below are descriptions of commonly used assembly DLL files:

ZwDatabaseMgd.dll: Contains interfaces for DWG database-related operations.

ZwManaged.dll: Provides interfaces for application operations, user interaction, printing, command/Lisp function definitions, and more.

ZdWindows.dll/ZcWindows.dll/ZcCui.dll: Contains interfaces for user interface customization.

How to Locate Assembly Files

It is recommended to reference assembly DLL files from the ZRXSDK. These files can be found in the "inc" folder under the ZRXSDK installation directory.

ZRXSDK can be downloaded from the ZWSOFT official website.

Note: While these assembly DLL files can also be found in the ZWCAD installation directory, they may have additional dependencies on other DLLs in the installation path and lack binary compatibility across versions. Therefore, using ZRXSDK assemblies is strongly recommended.

Namespaces Introduction

After referencing the assembly DLLs in your project, you can utilize the ZWCAD .NET API. The interfaces are organized into different namespaces. Below are descriptions of commonly used namespaces:

Namespace Overview of Interface Functionality
ZwSoft.ZwCAD.ApplicationServices Manages core functionalities such as application instances, documents, and user interaction.
ZwSoft.ZwCAD.DatabaseServices Provides database object management, entity operations, transaction handling, and access to symbol tables (e.g., block tables).
ZwSoft.ZwCAD.Runtime Supports command registration, extension loading, custom type handling, and interaction with ZWCAD runtime.
ZwSoft.ZwCAD.Geometry Enables creation of geometric objects, coordinate transformations, mathematical calculations, and operations on points, vectors, and matrices.
ZwSoft.ZwCAD.PlottingServices Manages print configurations, layout management, print output, page setups, and publishing operations.
ZwSoft.ZwCAD.GraphicsInterface Handles graphics rendering, entity drawing, viewport control, and visual effects processing.
