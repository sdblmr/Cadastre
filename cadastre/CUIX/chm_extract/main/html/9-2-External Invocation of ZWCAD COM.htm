External Program Invocation of ZWCAD COM Interface

Description

In the previous chapter, we introduced some common class libraries and usage of ZWCAD COM components. This chapter will demonstrate a typical example: how an external program can drive ZWCAD through its COM components to automate specific tasks.

Example Function Overview:

This chapter explains how to create a dialog application that invokes ZWCAD COM components to launch a ZWCAD.exe instance, open a DWG file, draw entities within the DWG, print these entities to a PDF file, and finally close the DWG file and exit ZWCAD.exe.

Create a Dialog Project:

Create a Windows Forms Application using Visual Studio Wizard, add buttons to the form, and implement event handlers for these buttons. This part is not the focus and will not be elaborated here.

Reference ZWCAD COM Components:

1. Right-click "References" in the Solution Explorer, browse to the local SDK, and add "ZwSoft.ZwCAD.Interop.dll" and "ZwSoft.ZwCAD.Interop.Common.dll". Then add using ZwSoft.ZwCAD.Interop;.

2. Right-click "References" in the Solution Explorer, browse to the ZWCAD installation directory, and add "zwcad.exe". Then add using ZWCAD;.

3. Right-click "References", select the COM tab, and add "ZWCAD 2025 Type Library". Then add using ZWCAD;.

Note: Choose only one of the above three methods to reference COM components. This example uses the first method.

Add the following code to the Start_ZWCAD_Click button event handler:

private void Start_ZWCAD_Click(object sender, EventArgs e)
{
   
    const string strProgId = "ZWCAD.Application.2026";
    try
    {
        zcadApp = (ZcadApplication)Marshal.GetActiveObject("ZWCAD.Application.2026");
    }
    catch
    {
        if (zcadApp == null)
        {
            try
            {
                // Create a new instance of ZWCAD
                zcadApp = Activator.CreateInstance(Type.GetTypeFromProgID(strProgId)) as ZcadApplication; 
            }
            catch 
            {
                System.Windows.Forms.MessageBox.Show("Instance of 'ZWCAD.Application.2026" +
                                                        " could not be created.");
                return;
            }
        }
    }

    if (zcadApp != null)
    {
        zcadApp.Visible = true; // Control ZWCAD UI visibility
    }
}

Key Function Explanation:

1. First, use Marshal.GetActiveObject("ZWCAD.Application.2026"); to retrieve an existing ZWCAD 2026 instance.

2. If the above step fails, create a new ZcadApplication instance via Activator.CreateInstance, which launches a new ZWCAD 2026 process.

3. zcadApp.Visible = true; controls the visibility of the ZWCAD 2026 UI. Setting it to false runs ZWCAD in silent mode (useful for automation scenarios).

Select DWG File:

Add the following code to the Select_File_Click button event handler:

private void Select_File_Click(object sender, EventArgs e)
{
    OpenFileDialog dialog = new OpenFileDialog();
    dialog.Multiselect = false;
    dialog.Title = "select dwg file";
    dialog.Filter = "dwg file(*.dwg)|*.dwg";
    if (dialog.ShowDialog() == System.Windows.Forms.DialogResult.OK)
    {
        string file = dialog.FileName;
        this.DwgFilePath.Text = file;
    }
}

Key Function Explanation:

This example uses OpenFileDialog to select a DWG file path for demonstration. For fully automated workflows, use non-dialog methods to avoid interrupting the process.

Open DWG Document:

Add the following code to the opendwg_Click button event handler:

private void opendwg_Click(object sender, EventArgs e)
{
    Object ReadOnly = false;
    Object Password = Type.Missing;
    Doc = zcadApp.Documents.Open(this.DwgFilePath.Text, ReadOnly, Password);
}

Key Function Explanation:

Set the object ReadOnly parameter in the Open function to false because this example will add entities to the dwg file, so it needs to be opened for writing. If you only need to read data without adding entities, set ReadOnly = true. Some drawings may have passwords; use Password to enter the password. If there is no password, assign Type.Missing.

Add Entities:

Add the following code to the button function Draw_Entities_Click in the "Draw Entities" dialog:

private void Draw_Entities_Click(object sender, EventArgs e)
{
    ZcadModelSpace ms = Doc.ModelSpace;
    ms.AddCircle(new double[] { 0, 0, 0 },10);
    ms.AddText("Hello World", new double[] { 0, 0, 0 }, 2.5);
}

Key Function Description:

In the previous chapter, we introduced how to use Doc.ModelSpace to obtain the model space instance. The "Add" methods provided by Doc.ModelSpace allow adding common entities (refer to VBA documentation for more methods to add different types of entities). This example demonstrates adding a circle with center coordinates at (0,0) and radius 10, and text with a height of 2.5 and content "Hello World".

Print PDF File:

Add the following code to the button function Plot_to_Pdf_Click in the "Plot to Pdf" dialog:

private void Plot_to_Pdf_Click(object sender, EventArgs e)
{
    ZcadLayout Layout;
    if (zcadApp.ActiveDocument.ActiveSpace == 0)
        Layout = Doc.PaperSpace.Layout;
    else
        Layout = Doc.ModelSpace.Layout;

    String MediaName = "ISO_A1_(594.00_x_841.00_MM)";
    try
    {
        ZcadPlotConfiguration oplot = Doc.PlotConfigurations.Add("PDF", Layout.ModelType);

        oplot.PaperUnits = ZcPlotPaperUnits.zcMillimeters;

        oplot.StyleSheet = "monochrome.ctb";

        oplot.PlotWithPlotStyles = true;

        oplot.ConfigName = "DWG To PDF.pc5";

        oplot.UseStandardScale = true;

        oplot.StandardScale = ZcPlotScale.zcScaleToFit;

        double[] dMinPoint, dMaxPoint;

        ZcPlotRotation acPlotRotation;

        FrameExtents(Doc, out dMinPoint, out dMaxPoint, out acPlotRotation);

        double[] dMinPointDCS, dMaxPointDCS;

        dMinPointDCS = Doc.Utility.TranslateCoordinates(dMinPoint, ZcCoordinateSystem.zcUCS, ZcCoordinateSystem.zcDisplayDCS, 0, new double[] { 0.0, 0.0, 0.0 });

        dMaxPointDCS = Doc.Utility.TranslateCoordinates(dMaxPoint, ZcCoordinateSystem.zcUCS, ZcCoordinateSystem.zcDisplayDCS, 0, new double[] { 0.0, 0.0, 0.0 });

        oplot.SetWindowToPlot(new double[] { dMinPointDCS[0], dMinPointDCS[1] }, new double[] { dMaxPointDCS[0], dMaxPointDCS[1] });

        oplot.PlotRotation = acPlotRotation;

        oplot.PlotType = ZcPlotType.zcWindow;

        oplot.CenterPlot = true;

        oplot.CanonicalMediaName = MediaName;

        Layout.CopyFrom(oplot);

        Layout.RefreshPlotDeviceInfo();

        Object nBACKGROUNDPLOT = 0, nFILEDIA = 0, nCMDDIA = 0;

        nBACKGROUNDPLOT = Doc.GetVariable("BACKGROUNDPLOT");
        nFILEDIA = Doc.GetVariable("FILEDIA");
        nCMDDIA = Doc.GetVariable("CMDDIA");

        Object xNull = 0;
        Doc.SetVariable("BACKGROUNDPLOT", xNull);
        Doc.SetVariable("FILEDIA", xNull);
        Doc.SetVariable("CMDDIA", xNull);

        Doc.Plot.QuietErrorMode = true;

        Doc.Plot.PlotToFile("d:/ZWCAD.pdf");

        Doc.SetVariable("BACKGROUNDPLOT", nBACKGROUNDPLOT);
        Doc.SetVariable("FILEDIA", nFILEDIA);
        Doc.SetVariable("CMDDIA", nCMDDIA);

        oplot.Delete();

        oplot = null;

        MessageBox.Show("plot succeed.");


    }
    catch (System.Exception es)
    {
        System.Windows.Forms.MessageBox.Show(es.ToString());

    }

}

Key Function Description:

The COM printing function is similar to the .NET printing chapter and will not be elaborated here. Note that this example uses the window plotting mode SetWindowToPlot for more precise printing. It also uses the Doc.Utility class library mentioned in the previous section, specifically the TranslateCoordinates function to convert UCS coordinates to DCS coordinates. This ensures accurate printing even if UCS and WCS coordinates differ. FrameExtents is a custom function to obtain the extents of all entities in the model space. The code is as follows:

private void FrameExtents(ZcadDocument Doc, out double[] outMinPoint, out double[] outMaxPoint, out ZcPlotRotation zcPlotRotation)
{
    outMinPoint = new double[] { 0.0, 0.0, 0.0 };
    outMaxPoint = new double[] { 0.0, 0.0, 0.0 };
    zcPlotRotation = ZcPlotRotation.zc0degrees; 
    double dAreaTemp = 0;

    var ss = Doc.SelectionSets.Add("plot");

    ss.Select(ZcSelect.zcSelectionSetAll, null, null, null, null);
    if (ss.Count > 0)
    {
        for (var i = 0; i < ss.Count; i++)
        {
            var entity = ss.Item(i);

            object MinPoint, MaxPoint;

            try
            {
                entity.GetBoundingBox(out MinPoint, out MaxPoint);
            }
            catch
            {
                continue; // Skip entities that cannot retrieve extents
            }

            double[] dMinPoint, dMaxPoint;

            dMinPoint = (double[])MinPoint;
            dMaxPoint = (double[])MaxPoint;

            // Determine the largest area as the plotting extent
            double dArea = (dMaxPoint[1] - dMinPoint[1]) * (dMaxPoint[0] - dMinPoint[0]);
            // Filter out entities with excessively large extents to avoid plotting errors
            if (dArea < 1000000000.0 && dArea > dAreaTemp)
            {
                dAreaTemp = dArea;
                outMinPoint = dMinPoint;
                outMaxPoint = dMaxPoint;

            }

        }

    }
    ss.Delete();

    if (outMaxPoint[1] - outMinPoint[1] < outMaxPoint[0] - outMinPoint[0])
    {
        zcPlotRotation = ZcPlotRotation.zc90degrees;
    }
}

Close DWG File:

Add the following code to the button function Close_Save_Click in the "Close Save" dialog:

private void Close_Save_Click(object sender, EventArgs e)
{
    Doc.Save();
    Doc.Close();
}

private void Quit_Click(object sender, EventArgs e)
