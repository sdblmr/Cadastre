Overview of ZWCAD .NET Secondary Development

Overview

ZWCAD .NET interface is a secondary development interface based on the Microsoft .NET framework, which supports deep extension of ZWCAD functions using languages such as C# and VB.net. This interface provides comprehensive control over graphic data, user interface, and document structure by encapsulating the ZWCAD object model. Developers can efficiently achieve tasks such as geometric creation, editing operations, custom commands, and interface customization. Its object-oriented design, seamless integration with the ZWCAD kernel, and cross version compatibility provide a stable and reliable development platform for building automation tools, industry plugins, or enterprise level design systems.

To use ZWCAD For secondary development using the .NET interface, developers need to first configure the development environment, write programs using the interfaces provided by the SDK, compile and generate the ZWCAD .NET application (DLL file), and finally load and run it in ZWCAD. In general, ZWCAD will not modify the interfaces in the SDK for 3-4 consecutive annual versions, so DLL files compiled using old versions of the SDK can be loaded on new versions. In binary compatible versions, developers do not need to modify the source code or recompile to upgrade to the new annual version of ZWCAD platform.

At the same time, in order to facilitate developers' learning and utilization of existing development resources, ZWCAD .NET interface is integrated into Autocad The .NET interface is very similar. About how to use Autocad For porting .NET programs to ZWCAD, please refer to the ZWCAD.NET Migration Guide.

Binary Compatibility

ZWCAD 2021~ZWCAD 2024 versions .NET secondary development programs are binary compatible and can be developed based on any version interface of ZWCAD 2021/22/23/24. The interface is compatible with Autocad 2019. The ZWCAD 2025 version has upgraded its interface and is compatible with Autocad 2024. It requires recompiling DLL files based on the ZWCAD 2025 interface before they can be loaded and used on ZWCAD 2025.

Development Environment

Developed for use The .NET Framework version requirement is 4.7. x (such as 4.7/4.7.1/4.7.2) Visual Studio recommends using 2017 (15.9 and above) and higher versions (such as 2019/2022/...)

Operating System

We recommend using Windows 10 (1703) and above versions, please refer to .NET Framework 4.7 system support.

Loading Program

In ZWCAD, the NETLOAD command can be used to load programs (DLL files). After the program is loaded, it cannot be uninstalled during the runtime of ZWCAD. If you need to modify the code and recompile it for loading, you need to first close ZWCAD or use the Edit and Continue function of Visual Studio. For details, please refer to Configuring Edit and Continue (C#, VB, C++).

Development Steps

The following is a brief step description for developing a ZWCAD .NET program, which will be further detailed in subsequent chapters:

1. Download and install ZRXSDK.

2. Create a VB.net or C# class library project in Visual Studio.

3. Take care of the project The .Net Framework version is set to 4.7.x.

4. In the project, reference DLL files such as ZwManaged. dll and ZwDatabase Mgd. dll from the inc folder in the ZRXSDK installation directory.

5. Use ZWCAD Write program code using the .NET interface.

6. Compile program code into DLL files in Visual Studio.

7. Start ZWCAD and use the NETLOAD command to load the DLL file generated in step 6.

Next, it can be executed Customized commands in .NET programs.

Related Commands

ZWCAD includes the following Command related to secondary development of .NET:

Command Describe
NETLOAD load .NET secondary development program files (DLL files).
NETDEBUG When debugging programs, breakpoints in dialog boxes and Jig callback functions cannot be triggered using regular debugging methods. This command is needed for debugging to correctly trigger these breakpoints.
