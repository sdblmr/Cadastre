ZWCAD 2026 .NET Developer's Guide
Auto Loading dll Files

Description

After developing a dll plugin, the manual approach is to load it using the NETLOAD command. However, when releasing a product, we cannot expect users to manually execute the command every time. We need an automatic method to load the dll so that the plugin is automatically attached when ZWCAD starts, enabling its features. Alternatively, this automatic loading mechanism can be packaged into a professional product installer (exe).

Registry Loading

Registry loading enables automatic loading of secondary development programs. It can also be implemented via third-party installer scripts that modify the registry. The method involves registering the secondary development program under specific registry entries. The relevant registry paths are:

HKEY_LOCAL_MACHINE\SOFTWARE\ZWSOFT\ZWCAD\2026\zh-CN\Applications
HKEY_CURRENT_USER\Software\ZWSOFT\ZWCAD\2026\zh-CN\Applications

The difference between these two entries is that HKEY_LOCAL_MACHINE applies to all users, while HKEY_CURRENT_USER applies only to the current user.

You can write the registration information into a .reg file and import it into the registry to enable on-demand loading. The following .reg file example demonstrates the on-demand loading of the ZWTest.dll program:

Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\ZWSOFT\ZWCAD\2026\zh-CN\Applications\ZWTest]
"LOADER"="ZWTest.dll"
"LOADCTRLS"=dword:00000002
"DESCRIPTION"=""
"Managed"=dword:00000001

[HKEY_LOCAL_MACHINE\SOFTWARE\ZWSOFT\ZWCAD\2026\zh-CN\Applications\ZWTest\Commands]
"ZWTest"="ZWTest"

[HKEY_LOCAL_MACHINE\SOFTWARE\ZWSOFT\ZWCAD\2026\zh-CN\Applications\ZWTest\Groups]
"NET_ZWTest_COMMANDS"="NET_ZWTest_COMMANDS"

This registers the command ZWTest under the command group NET_ZWTest_COMMANDS. The loading method is set to 00000002, which loads the plugin when ZWCAD 2026 starts. To enable on-demand loading (i.e., loading only when the registered command is executed), set the loading method to 00000008.

  • LOADER specifies the program file to load. It can include a path or omit it. If omitted, the file is searched according to the file search order.

  • LOADCTRLS defines the loading method.

  • DESCRIPTION provides descriptive text for the program.

  • Managed set to 00000001 indicates a managed program.

  • Commands lists the commands registered by the program.

  • Groups lists the command group names registered by the program.

Note

In the registry paths above, "zh-CN" represents the Chinese version. For the English version, use "en-US". For the Mechanical version, the registry path is: HKEY_LOCAL_MACHINE\SOFTWARE\ZWSOFT\ZWCADM\2026:

ZWCAD2026.lsp Auto-Loading

This file is automatically loaded and executed when ZWCAD 2026 starts. You can add LISP code to this file to load secondary development programs. For example, to auto-load ZWTest.dll, add the following code:

(command "netload" "ZWTest.dll")

Notes

  • The default location of ZWCAD2026.lsp is in the installation directory. For the Mechanical version, it is ZWCADM2026.lsp:

    Platform version: C:\Program Files\ZWSOFT\ZWCAD 2026\Support

    Mechanical version: C:\Program Files\ZWSOFT\ZWCAD Mechanical 2026 Chs\Support

  • When specifying the file, you can use a full path or just the filename. If only the filename is provided, ZWCAD 2026 searches in the following order: current working directory, support file search paths defined in options, and finally the ZWCAD.EXE directory. This search order applies to all files without specified paths in ZWCAD 2026.
