Editor Events

Commonly used editor events: The Point Monitor can capture the mouse position in real-time and display tooltips. The Point Filter can modify the actual coordinates selected by the user in real-time.

Common Editor Events

Event Function Overview Usage
PointMonitor Point Monitor The PointMonitorEventArgs parameter provides the current model space coordinates of the mouse and the underlying entity. Use the AppendToolTipText method to display entity-related tooltips near the mouse.
PointFilter Point Filter The PointFilterEventArgs parameter provides the current model space coordinates of the mouse. By processing and setting new coordinates to the corresponding parameter, the actual coordinates selected by the user can be modified in real-time.

Adding and Removing Document Events

Adding Events

    static public void AddEdEvents()
    {
        Database db = HostApplicationServices.WorkingDatabase;
        Document doc = Application.DocumentManager.GetDocument(db);
        Editor ed = doc.Editor;

        try
        {
            ed.PointMonitor += Ed_PointMonitor;
            ed.PointFilter += Ed_PointFilter;
        }
        catch (Exception ex)
        {
            Application.ShowAlertDialog(ex.ToString());
        }

        ed.WriteMessage("\nEditor Events Added!");
    }

Removing Events

    static public void RemoveEdEvents()
    {
        Database db = HostApplicationServices.WorkingDatabase;
        Document doc = Application.DocumentManager.GetDocument(db);
        Editor ed = doc.Editor;

        try
        {
            ed.PointMonitor -= Ed_PointMonitor;
            ed.PointFilter -= Ed_PointFilter;
        }
        catch (Exception ex)
        {
            Application.ShowAlertDialog(ex.ToString());
        }

        ed.WriteMessage("\nEditor Events Removed!");
    }

Defining Event Handlers

In event handlers, the second parameter typically contains the current mouse coordinates and the set of entities under the cursor.

PointMonitor

    private static void Ed_PointMonitor(object sender, PointMonitorEventArgs e)
    {
        // Get the entity under the mouse
        FullSubentityPath[] fsp = e.Context.GetPickedEntities();
        if (fsp.Length > 0)
        {
            // Display the handle of the topmost entity
            e.AppendToolTipText($"Entity Handle: {fsp[0].GetObjectIds()[0].Handle.ToString()}");
        }
    }

PointFilter

    private static void Ed_PointFilter(object sender, PointFilterEventArgs e)
    {
        Point2d lastPt = e.Context.LastPoint.Convert2d(new Plane());
        Point2d computedPt = e.Context.ComputedPoint.Convert2d(new Plane());

        double angle = lastPt.GetVectorTo(computedPt).Angle;

        // Restrict new points to horizontal or vertical directions relative to the previous point
        if (angle > 0.785 && angle < 2.356 || angle > 3.927 && angle < 5.498)
        {
            e.Result.NewPoint = new Point3d(e.Context.LastPoint.X, e.Context.ComputedPoint.Y, 0);
        }
        else
        {
            e.Result.NewPoint = new Point3d(e.Context.ComputedPoint.X, e.Context.LastPoint.Y, 0);
        }
    }
