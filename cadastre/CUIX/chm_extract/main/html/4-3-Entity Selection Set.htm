Selection Set

Description

A selection set is a collection of entities selected by the user or program, serving as a crucial means of interaction. It allows you to retrieve information from the drawing window through selected entities. You can either prompt the user to select entities or use filters for conditional screening. After selecting objects via a selection set, further processing can be performed. This section explains how to select entities under specific conditions using common selection set functions.

Selection Set Functions Overview

The table below lists common selection set functions. Subsequent articles will demonstrate how to use these functions.

Function Name Purpose
GetSelection() Select entities in the graphics window
SelectAll() Select all entities
SelectCrossingWindow() Select entities within or intersecting the window boundaries
SelectCrossingPolygon() Select entities inside or intersecting a polygon
SelectFence() Select entities along a fence line
SelectImplied() Select pre-selected entities in the current graphics window
SelectLast() Select the most recently created entity
SelectPrevious() Select the previous selection set
SelectWindow() Select entities inside a rectangular window
SelectWindowPolygon() Select entities inside a polygonal window

Select Entities Using GetSelection()

[CommandMethod("Select_GetSelection")]
static public void GetSelectionTest()
{
    Database db = HostApplicationServices.WorkingDatabase;
    Document doc = Application.DocumentManager.GetDocument(db);
    Editor ed = doc.Editor;

    PromptSelectionOptions selOpts = new PromptSelectionOptions();
    selOpts.MessageForAdding = "Select some entities: ";

    TypedValue[] values = { new TypedValue(0, "LINE"), new TypedValue(62, 1) };
    SelectionFilter filter = new SelectionFilter(values);

    PromptSelectionResult selRes = ed.GetSelection(selOpts, filter);
    if (selRes.Status != PromptStatus.OK)
        return;

    SelectionSet sSet = selRes.Value;
    ObjectId[] objIds = sSet.GetObjectIds();
    ChangeColor(objIds);

    ed.WriteMessage("\nThe selection set has {0} object", objIds.Length);
}

Result:

Draw entities such as circles, multiple lines (change one line's color to red), and polylines. Execute Select_GetSelection and select all entities. The command line outputs: "The selection set has 1 object". Only the red line turns blue.

SelectionFilter Introduction:

Filters can be applied to select entities meeting specific conditions. For example, in the code above: "TypedValue[] values = { new TypedValue(0, "LINE"), new TypedValue(62, 1) };" adds two conditions: "entity is a line" and "color is red".

Common DXF Group Codes:

1. 0(DxfCode.Start): Object type (string), e.g., "Line", "Arc". Note: Polyline uses "LWPOLYLINE", BlockReference uses "INSERT".

2. 1(DxfCode.Text): Primary text value (string), e.g., text content or attribute string.

3. 2(DxfCode.BlockName): Object name (string), e.g., attribute tag, block name.

4. 8(DxfCode.LayerName): Layer name (string).

5. 10(DxfCode.XCoordinate): Primary point (start point of a line, center of a circle, etc.), represented as a 3D coordinate array.

6. 60(DxfCode.Visiblility): Visibility (integer), 0=visible, 1=invisible.

7. 62(DxfCode.Color): Color index (integer), 0=ByBlock, 256=ByLayer.

8. 1000(DxfCode.ExtendedDataASCIIString): Extended data ASCII string (up to 255 bytes).

9. 1001(DxfCode.ExtendedDataRegAppName): Extended data registered application name (up to 31-byte ASCII string).

GetSelection() with Keywords

[CommandMethod("Keyword_GetSelection")]
public void Keyword_GetSelection()
{
    var doc = Application.DocumentManager.MdiActiveDocument;
    var db = doc.Database;
    var ed = doc.Editor;

    PromptSelectionOptions selOpts = new PromptSelectionOptions();
    // Add branch option names. Uppercase letters in the string are keywords, allowing users to input only the keyword during command execution to trigger the corresponding branch.
    selOpts.Keywords.Add("Atest");
    selOpts.Keywords.Add("Btest");
    // Display all branches in the prompt message using GetDisplayString
    selOpts.MessageForAdding = "Select some entities: " + selOpts.Keywords.GetDisplayString(true);
    // Add event handler for keyword input
    selOpts.KeywordInput += SelOpts_KeywordInput;
    var propRes = ed.GetSelection(selOpts);
    ...
}

private void SelOpts_KeywordInput(object sender, SelectionTextInputEventArgs e)
{
    Application.DocumentManager.MdiActiveDocument.Editor.WriteMessage(e.Input);
}

Running Results:

After executing the Keyword_GetSelection command, input keywords A or B in the command line. The command line will display the strings "Atest" or "Btest".

Crossing Polygon SelectionSelectCrossingPolygon()

[CommandMethod("Select_CrossingPolygon")]
static public void SelectCrossingPolygon()
{
    Database db = HostApplicationServices.WorkingDatabase;
    Document doc = Application.DocumentManager.GetDocument(db);
    Editor ed = doc.Editor;

    Point3d[] pt3dArr = new Point3d[5];
    pt3dArr[0] = new Point3d(0, 0, 0);
    pt3dArr[1] = new Point3d(1000, 0, 0);
    pt3dArr[2] = new Point3d(1000, 1500, 0);
    pt3dArr[3] = new Point3d(0, 1000, 0);
    pt3dArr[4] = new Point3d(0, 0, 0);

    Point3dCollection pt3dCol = new Point3dCollection(pt3dArr);

    PromptSelectionResult selRes = ed.SelectCrossingPolygon(pt3dCol);
    if (selRes.Status != PromptStatus.OK)
        return;

    SelectionSet sSet = selRes.Value;
    ObjectId[] objIds = sSet.GetObjectIds();

    ed.WriteMessage("\nThe selection set has {0} object", objIds.Length);
    ChangeColor(objIds);
}

Running Results:

As shown in the figure: Entities inside or intersecting with the polygon formed by coordinates (0,0), (1000,0), (1000,1500), and (0,1000) are selected. The ChangeColor function turns them blue, and the command line outputs: "The selection set has 7 object".

ChangeColor() Function

static public void ChangeColor(ObjectId[] objIds)
{
    Database db = HostApplicationServices.WorkingDatabase;
    Document doc = Application.DocumentManager.MdiActiveDocument;
    Editor ed = doc.Editor;

    using (Transaction trans = db.TransactionManager.StartTransaction())
    {
        foreach (ObjectId objId in objIds)
        {
            Entity entity = (Entity)objId.GetObject(OpenMode.ForWrite);
                entity.ColorIndex = 5;
        }
        trans.Commit();
    }
}
